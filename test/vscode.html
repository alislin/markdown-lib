VSCode Markdown Preview 主题：

VSCode Markdown 预览示例

这是模拟 Visual Studio Code Markdown 预览的测试页面。

项目结构

project/
├── src/
│   ├── index.js
│   └── styles.css
├── package.json
└── README.md

安装与使用

安装依赖：

npm install

运行开发服务器：

npm run dev

配置选项

选项 类型 默认值 说明
theme string 'auto' 主题模式：auto / light / dark
fontSize number 16 基础字号
lineHeight number 1.6 行高

注意事项

  • 确保已安装 Node.js 16+
  • 推荐使用 VSCode 的 Markdown All in One 插件
  • 支持实时预览和导出 PDF

提示：VSCode 会根据当前编辑器主题自动切换预览主题。

快捷键

常用快捷键：

  • Ctrl + Shift + V - 打开预览
  • Ctrl + K V - 侧边预览
  • Ctrl + B - 切换侧边栏

此页面模拟 VSCode Markdown 预览环境，用于测试主题在 VSCode 场景下的显示效果。
