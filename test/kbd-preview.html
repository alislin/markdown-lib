KBD 键盘按键样式方案对比

选择你喜欢的键盘按键立体效果风格

方案 A：基础样式（当前默认）

简单背景色 + 细边框

快捷键：Ctrl + C 复制

组合键：Ctrl + Shift + N 新建窗口

单独按键：Enter Esc Tab Space

方案 B：轻度立体效果

底部粗边框 + 下移阴影

快捷键：Ctrl + C 复制

组合键：Ctrl + Shift + N 新建窗口

单独按键：Enter Esc Tab Space

方案 C：经典键盘按键效果

渐变背景 + 多层阴影 + 高光

快捷键：Ctrl + C 复制

组合键：Ctrl + Shift + N 新建窗口

单独按键：Enter Esc Tab Space

方案 D：macOS 风格

圆角按键 + 轻柔阴影 + 系统字体

快捷键：⌘ + C 复制

组合键：⌘ + ⇧ + N 新建窗口

单独按键：Return Esc Tab Space

方案 E：Windows 风格

方正按键 + 明显阴影 + Segoe UI 字体

快捷键：Ctrl + C 复制

组合键：Ctrl + Shift + N 新建窗口

单独按键：Enter Esc Tab Space

💡 说明
  • 方案 A：当前默认样式，最简单
  • 方案 B：轻度立体感，简洁但有按键感
  • 方案 C：经典键盘按键，立体效果最明显（推荐）
  • 方案 D：macOS 风格，优雅圆润
  • 方案 E：Windows 风格，方正实用

可以在浅色/深色模式下切换查看效果对比。
