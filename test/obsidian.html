MD-Green 主题测试笔记

这是一篇在 Obsidian 中创建的笔记，用于测试 MD-Green 主题样式。

什么是 Obsidian？

Obsidian 是一款强大的知识库管理工具，支持：

  • 双向链接 - 使用 [[笔记名]] 创建链接
  • 图谱视图 - 可视化笔记之间的关系
  • 插件生态 - 丰富的社区插件
  • 本地存储 - 数据完全由你掌控

💡 提示：MD-Green 主题可以通过 CSS 代码片段的方式应用到 Obsidian 中。

快速开始

  1. 打开设置 → 外观 → CSS 代码片段
  2. 创建新片段，命名为 md-green
  3. 将编译后的 CSS 内容粘贴进去
  4. 启用该片段

代码示例

```css
/* 在 Obsidian 中覆盖变量 */
:root {
  --md-bg-primary: var(--background-primary);
  --md-text-primary: var(--text-normal);
}
```
