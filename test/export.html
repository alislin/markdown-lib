MD-Green Theme 导出示例

这是一个使用 MD-Green 主题渲染的 Markdown 文档导出示例，模拟 VSCode 导出 HTML 格式。

简介

MD-Green 是一个支持深浅色主题切换的 Markdown 样式库，适用于：

  • VSCode Markdown 预览
  • Obsidian 笔记应用
  • Docsify 文档网站
  • 导出的静态 HTML 文档

特性

  1. 自动跟随系统主题
  2. 支持手动切换主题
  3. CSS 变量便于自定义
  4. 模块化 SCSS 源码

安装

npm install md-green-theme

使用方法

<link rel="stylesheet" href="md-green.css">

主题切换

手动切换主题：

<html data-theme="dark">  <!-- 强制深色 -->
<html data-theme="light"> <!-- 强制浅色 -->

CSS 变量

:root {
  --md-bg-primary: #your-color;
  --md-text-primary: #your-color;
}

配置表格

变量名 说明 默认值
--md-bg-primary 主背景色 #ffffff
--md-text-primary 主文本色 #444444
--md-link 链接色 #0099ff

输出文件

文件 大小 说明
md-green.css ~11KB 完整版
md-green-light.css ~7KB 浅色版
md-green-dark.css ~6KB 深色版
