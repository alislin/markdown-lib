MD-Green Markdown 主题演示

这是一个使用 MD-Green 主题渲染的 Markdown 文档。

简介

MD-Green 是一个支持深浅色主题切换的 Markdown 样式库，适用于：

  • VSCode Markdown 预览
  • Obsidian 笔记应用
  • Docsify 文档网站
  • 导出的静态 HTML 文档

特性

  1. 自动跟随系统主题
  2. 支持手动切换主题
  3. CSS 变量便于自定义
  4. 模块化 SCSS 源码

代码示例

function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet('World'));

表格数据

版本 文件 说明
完整版 md-green.css 支持自动/手动主题切换
浅色版 md-green-light.css 固定浅色主题
深色版 md-green-dark.css 固定深色主题
基础版 md-green-base.css 无主题，供自定义

主题切换

如需手动切换主题，在 <html> 标签上添加 data-theme 属性：

<html data-theme="dark">  <!-- 强制深色 -->
<html data-theme="light"> <!-- 强制浅色 -->
